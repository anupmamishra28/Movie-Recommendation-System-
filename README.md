# Movie-Recommendation-System-
A simple Movie Recommendation System using Python and machine learning to suggest similar movies based on user input
This project is a simple Movie Recommendation System developed using Python. The main idea behind this project is to help users find movies similar to the one they like. Sometimes it becomes confusing to choose what to watch because there are so many options available, so this system tries to make that process easier
The objective of this project is to build a basic recommendation system using machine learning concepts and understand how similarity between data can be used to suggest relevant results.
	•	Python
	•	Pandas
	•	Scikit-learn
the system takes a movie name as input from the user. It then compares that movie with other movies in the dataset based on their genres. Using a technique called cosine similarity, it finds movies that are most similar and displays them as recommendations.
